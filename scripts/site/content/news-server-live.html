The Thornvale server is live

Thornvale's first online server is up. You can create an account, make up to five characters and start exploring right now, in your browser, with nothing to download.

The world is still being built, and the full grand opening is on 1 January 2027. Accounts and character names you make now carry over to launch, so it's a good time to claim the name you want.
